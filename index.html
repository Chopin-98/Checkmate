Guide d'utilisation : Chess Graph & Répertoire

Bienvenue dans le module d'entraînement aux ouvertures !

  • 1. Créer votre répertoire : Sur Chess Graph, créez votre répertoire d'ouvertures.
  • 2. Exporter : Téléchargez votre répertoire.
  • 3. Importer : Importez le fichier dans Checkmate.
  • 4. S'entraîner : Entraînez-vous à réciter votre répertoire ou relevez le Mode Défi Chrono !
